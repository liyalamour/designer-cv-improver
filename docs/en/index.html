Codex — native skill

  1. Download and unzip the package, then place the full folder in ~/.codex/skills/designer-cv-improver/.
  2. Save it as SKILL.md in that folder.
  3. Start a CV task naturally; Codex can load the skill when it fits.
“Tailor my product design CV to this role.
Keep it ATS-safe and ask for missing metrics.”

ChatGPT — project guidance

  1. Create a new Project for CV work.
  2. Upload the downloaded Markdown file as a project source.
  3. In Project settings, add: “Use the Designer CV Improver playbook in the attached source for CV tasks.”
“Use the attached CV playbook to critique this resume
for a senior product designer role.”

Claude Code — repository guidance

  1. Copy the downloaded Markdown into a CLAUDE.md file at your project root.
  2. Keep the instruction focused on the CV workflow; link to supporting references when you have them.
  3. Run Claude Code from that project and attach or paste your CV.
“Read CLAUDE.md, then improve this CV without
inventing metrics or outcomes.”

Cursor — project rule

  1. Create .cursor/rules/designer-cv-improver.mdc.
  2. Paste the playbook, add a short description, and set it as an Agent Requested rule.
  3. Ask Cursor to apply the rule when reviewing a CV.
“Apply @designer-cv-improver and rewrite these
experience bullets for a design lead role.”
From feedback to file

Recommendations applied, not left in a checklist.

Choose the format that suits your next application. The skill can turn the approved content into a polished PDF or an editable Figma layout—after the evidence, hierarchy, and wording are improved.

Important: visual CV work starts with at least two genuinely different directions, so you select the route before a final file is made.

PDF

Verified PDF

A ready-to-send CV designed for a confident recruiter scan.

  • Applied summary and bullet improvements
  • Rendered and checked for spacing, links, contrast, and overlaps
  • One-page balance or a deliberate second page—never cramped text
FIG

Editable Figma file

A layout you can continue tailoring for each application.

  • Improved content placed in an editable frame
  • Two visual directions before final selection
  • Clear hierarchy for identity, experience, education, and supporting evidence
