一套流程，四種 AI 平台用法。

下載檔是可攜式 Markdown 操作手冊。Codex 可作為原生 Skill 使用；其他平台則能轉為可重複使用的專案指引。請選擇你使用的工作環境。

下載 .SKILL.md

履歷證據與審查標準完全一致，改變的只有你儲存指引的位置。

Codex — 原生 Skill

  1. 下載檔案後，建立 ~/.codex/skills/designer-cv-improver/.
  2. 將檔案命名為 SKILL.md 並放入該資料夾。
  3. 直接開始履歷任務；當任務適合時，Codex 會載入此 Skill。
「請依照這個職缺調整我的產品設計履歷；保持 ATS 友善，並標示需要補充的數據。」

ChatGPT — 專案指引

  1. 為履歷工作建立新的 專案。
  2. 把下載的 Markdown 檔上傳為專案來源。
  3. In Project settings, add: “Use the 設計師履歷優化器 playbook in the attached source for CV tasks.”
「請使用附加的履歷操作手冊，檢視這份資深產品設計師職缺的履歷。」

Claude Code — 專案指引

  1. 把下載的 Markdown 複製到專案根目錄的 CLAUDE.md 檔案中。
  2. 聚焦保留履歷工作流程；若有補充資料，可再加入對應連結。
  3. 從該專案啟動 Claude Code，並附上或貼上你的履歷。
「請先閱讀 CLAUDE.md，再改善這份履歷；不要杜撰數據或成果。」

Cursor — 專案規則

  1. Create .cursor/rules/designer-cv-improver.mdc.
  2. 貼上操作手冊、補上一段簡短說明，並設為 Agent Requested 規則。
  3. 請 Cursor 在審閱履歷時套用此規則。
「套用 @designer-cv-improver，將這些工作經歷改寫為設計主管職缺適用的版本。」
從建議到成品

不只提供建議，而是把建議真正套用到成品。

依下一份職缺的需求選擇格式。內容、層級與措辭改善後，這套 Skill 能輸出精緻 PDF 或可編輯的 Figma 版型。

提醒： 視覺履歷會先提供至少兩個真正不同的方向，再由你選擇後製作最終檔案。

PDF

驗證完成的 PDF

可直接投遞、讓招募者快速掌握重點的履歷。

  • 已套用的摘要與經歷描述優化
  • 已渲染並檢查間距、連結、對比與重疊
  • 平衡的一頁式版面，或有策略的第二頁；絕不壓縮到難以閱讀
FIG

可編輯的 Figma 檔案

可為每一份職缺繼續調整的版型。

  • 改善後的內容放入可編輯畫面
  • 定稿前先比較兩個視覺方向
  • 清楚安排個人資訊、工作經歷、學歷與支持證據的層級
